## Einleitung

Herzlich willkommen zur Videokonferenzplattform PILOS. Diese Kurzanleitung soll Ihnen einen schnellen Einstieg ermöglichen und zeigen, wie Sie einen neuen Raum erstellen können.

## Anmelden

Klicke Sie oben rechts in der Ecke auf "Anmelden".

![home](assets/intro/home.png)
Wählen Sie anschließend Ihre Anmeldeart aus. Es gibt verschiedene Möglichkeiten sich anzumelden, je nachdem wie die PILOS-Installation aufgesetzt wurde.

:::note
  Ihre Organisation könnte die Möglichkeiten sich anzumelden anders benannt haben, wie etwa "Generischer Universitätslogin". Dies entspricht für gewöhnlich LDAP oder Shibboleth.
:::

<Tabs>
  <TabItem value="shib" label="Shibboleth" default>
   Mit Klicken des “Anmelden” Buttons öffnet sich die Standard Anmeldemaske ihrer Organisation. Nach der Anmeldung dort, werden Sie wieder zu PILOS weitergeleitet.

   [ldap](assets/intro/shib.png)

  </TabItem>
  <TabItem value="ldap" label="LDAP" default>
    Geben Sie ihre LDAP-Benutzer-ID und das zugehörige Passwort in die Anmeldemaske ein (1-2) and klicken Sie dann auf "Anmelden"(3).

   [ldap](assets/intro/ldap.png)

  </TabItem>
  <TabItem value="email" label="Email">
   Wenn Sie Anmeldedaten speziell für die Nutzung von PILOS zur Verfügung gestellt bekommen haben, ist dies die richtige Anmeldeoption.

   Geben Sie ihre Emailadresse und das zugehörige Passwort ein (1-2) und klicken Sie dann auf "Anmelden" (3).

  :::tip
    Sollten Sie ihr Passwort vergessen haben, können Sie hier auf “Passwort vergessen?” klicken, um einen Link zur Zurücksetzung des Passworts per Email zugesendet zu bekommen.
  :::

  [email](assets/intro/email.png)
  </TabItem>
</Tabs>

## 2. Raum erstellen

Sie befinden Sie nun auf Ihrer persönlichen Startseite, auf welcher Sie Ihre eigenen Räume finden. Weiterhin werden Ihnen hier auch Ihre Raummitgliedschaften angezeigt.

Um einen neuen Raum zu erstellen, klicken Sie unter dem Abschnitt “Meine Räume” auf “Neuen Raum erstellen”.

[startpage](assets/intro/startpage.png)

In dem sich öffnenden Popup-Fenster wählen Sie die gewünschte Raumart (1) aus, legen einen Namen für den Raum fest (2) und klicken auf “Erstellen” (3).
[neu](assets/intro/neu.png)

## 3. Raum starten

Der neue Raum wurde erstellt und Sie können diesen nun verwenden. Um den Raum mit weiteren Nutzern zu teilen, klicken Sie auf den Kopieren-Button (1) und verteilen die kopieren Informationen beispielsweise per E-Mail.

Wenn Sie den Videokonferenzraum starten möchten, klicken Sie auf "Starten" (2).

## 4. Raum anpassen

:::note Dieser Schritt ist optional
:::

Der Raum ist aktuell mit einem Zugangscode geschützt und kann nur von angemeldeten Nutzern verwendet werden. Schauen Sie sich die restliche Dokumentation an, um zu lernen wie Sie den Raum an Ihre Bedürfnisse anpassen können. Viel Erfolg!
